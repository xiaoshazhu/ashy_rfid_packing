# TD-39 RS485 全 12 路监听与前 5 路业务测试说明

## 已按设备手册设置的通信参数

- Modbus-RTU 从站地址：1
- 串口：9600、8 数据位、无校验、1 停止位（9600/8N1）
- 读取功能码：`0x01`
- 监测范围：`00001~00012`，对应模块全部 DI0~DI11
- 业务触发范围：软件通道 1~5，对应模块端子 DI0~DI4
- 查询帧：`01 01 00 00 00 0C 3C 0F`
- 轮询间隔：50ms，兼容持续时间较短的输入脉冲

`0x01` 是只读查询，不会修改 TD-39 模块的参数。

## 干接点输入必须使用外部输入配电

TD-39 的 `ICOM/DI` 输入端不会在内部自动产生检测电压，因此只短接
`ICOM-DI` 不会亮灯，也不会产生闭合状态。干接点是无源开关，但输入回路仍必须
由外部直流电源提供电流。

现场已经测得 `ICOM` 与 `GND` 相通，应采用漏型接线：

```text
GND ---------------- ICOM

+VS ---- 常开按钮 ---- DI0
+VS ---- 常开按钮 ---- DI1
+VS ---- 常开按钮 ---- DI2
+VS ---- 常开按钮 ---- DI3
+VS ---- 常开按钮 ---- DI4
```

不要保留绕过按钮的 `+VS-DI` 直连线，否则对应输入会一直闭合，按钮动作无法造成
电平变化。`+VS` 指模块供电正极，不是 RS485 的 `DATA+`。

如果现场改为 `ICOM` 接 `+VS`，则每个按钮的另一端应改接 `GND`。两种接法只能
选择一种，不能混用。

正式软件当前按以下方式处理“按下”沿：

| 软件通道 | 模块端子 | 触发的软件功能 |
| --- | --- | --- |
| 1 | DI0 | 复位 |
| 2 | DI1 | 打印箱码 |
| 3 | DI2 | 拍照识别 |
| 4 | DI3 | 重新装箱 |
| 5 | DI4 | 光电到位触发拍照识别 |

## 方法一：在正式软件运行时监听

1. 正常双击 `start.bat` 启动装箱扫码软件。
2. 在设置中确认选择的是 USB-RS485 转换器对应的 COM 口。
3. 依次按下并释放接在前 5 路的按钮或传感器。
4. 关闭软件后，查看：
   - `logs\rs485_input_monitor.log`：专用输入监听日志；
   - `logs\app_log.log`：正式软件完整业务日志。

专用日志中的关键字：

- `START`：监听线程已启动，并显示 COM 口和查询帧；
- `RX-RAW`：串口已经收到原始字节；
- `RX-VALID`：已收到 CRC 正确的 TD-39 响应；
- `STATE-CHANGE`：DI0~DI11 中至少一路发生变化；
- `CHANNEL-EVENT`：具体是哪一路、是闭合还是断开；
- `HEARTBEAT`：通信正常，但最近 5 秒输入状态没有变化；
- `INPUTS-UNCHANGED`：通信持续正常，但端子电平一直不变，应检查 ICOM 和按钮触点接线；
- `NO-VALID-RESPONSE`：没有收到有效响应，需要检查串口或接线。

## 方法二：单独运行现场检测工具

1. 先关闭正式软件和其他串口工具。同一个 COM 口不能被两个程序同时占用。
2. 双击 `顶部按钮通道探测.bat`。
3. 工具会优先使用 `config.json` 中保存的 COM 口，然后自动检测其他串口。
4. 看到“找到有效 TD-39 响应”后，依次按下和释放前 5 路输入。
5. 窗口会显示 `CHANNEL-EVENT`，例如：

   ```text
   CHANNEL-EVENT no=1 通道1(DI0) -> 闭合
   CHANNEL-EVENT no=2 通道1(DI0) -> 断开
   ```

6. 按 `Ctrl+C` 结束，结果保存在 `logs\rs485_input_probe.log`。

如果需要明确指定串口，可在命令提示符中运行：

```bat
start_rs485_input_probe.bat --port COM21
```

## 没有收到数据时的排查顺序

1. 确认 TD-39 模块已有 9~30V 直流供电；
2. 确认 USB-RS485 转换器驱动正常，Windows 设备管理器中能看到 COM 口；
3. 确认设置页选中的 COM 口和设备管理器一致；
4. 交换 RS485 的 A、B 两根线后重试；
5. 确认模块站号仍为 1、波特率仍为 9600；
6. 确认按钮信号接在 DI0~DI4，公共端 ICOM 接线符合 NPN/PNP 输入方式。
