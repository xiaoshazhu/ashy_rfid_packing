samplecode	-----  提供C++、C#、java，html-javascript的示例执行工程，通过调用C函数型功能接口实现热敏功能			
web_server	-----web服务程序
tutorial		------以视频的形式演示bin目录下的Demo使用教程

/*------------------- en-US -------------------*/

[Overview]
1. This SDK package supports various series of thermal printers
2. This SDK package supports 32/64 bit XP, 7, 10, 11 and other Windows systems under x86 architecture
3. This SDK package currently supports zh CN, which stands for Simplified Chinese

[Catalog Description]
Bin - Place 32/64 bit demo programs and trial templates
Doc - Place SDK usage instructions document
Include - Place the C language header file that matches the dynamic library
Lib - places 32/64 bit dynamic libraries and their corresponding link symbol files, among which plugins currently provide xpdf plugin for supporting PDF printing
Samplecode - provides example execution projects for C++, C #,  Java, and HTML JavaScript, implementing thermal functionality by calling C functional interfaces
Web_Server -- Web Service Program
Tutorial - demonstrate the demo usage tutorial in the bin directory in the form of a video

[Version Detail]
libDSThermal.dll/libDSThermal.so  :  V1.3.0.0
DSTP2xWebPrtServer.exe/DSTP2xWebPrtServer.out : V1.2.0.0
DSTP2xDemo.exe/DSTP2xDemo.out : V1.1.0.1

[Change Log]
If there is a new version in the future, the changed content can be found in the "Win_ChangeLog. txt" directory at this level.

[Terminology Explanation]
C functional interface: a traditional C language function that corresponds one-to-one with printer functions.

[Usage suggestion]
1. If you have a certain understanding of the functions and related concepts of the above series of thermal printers, it will be helpful for subsequent programming work based on this SDK.
2. If you have any questions during use, please feel free to consult our company's technical support.
