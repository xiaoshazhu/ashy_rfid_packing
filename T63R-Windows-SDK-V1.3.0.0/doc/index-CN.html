SDK 是一种免安装驱动、灵活可控的应用程序开发支持。
本文档将从：环境要求，打印机适配，支持功能，调用流程，功能接口，Demo使用说明，常见问题和相关返回码附表等方面展开叙述，以便帮助开发人员基于本 SDK 快速构建其所需打印功能的应用程序。

1、适用范围

本 SDK 适用于具备以下能力或条件的广大程序开发人员：
① Windows 或 linux 系统下基于 C 语言动态库功能接口编写应用程序。
② 对条码标签打印机功能，使用规范有一定了解的人员。
③ 对 RFID 读写功能有一定了解的人员。

2、系统平台

① Windows PC 平台（32/64 位）：XP，win7，win8，win8.1，win10 等。
② VC 运行时环境支持等。
③ Linux 平台，支持 x86_64、 aarch64 平台。

3、编程语言

支持基于.dll 的编程语言包括但不限于：C/C++、C#、Basic（VB， VB .NET）、Pascal（Delphi）、Java、PowerScript（PB）。
支持基于.so 的编程语言包括但不限于：C/C++、 Java。
支持基于 http 的 web api 调用包括但不限于：javascript、C#、C++。
