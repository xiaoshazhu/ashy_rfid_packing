SDK is a flexible and controllable application development support without installation.
This document will explain from: environment requirements, printer adaptation, support functions, call flow, functional interfaces, demo instructions, FAQs and related return code schedules, etc., to help developers quickly build applications for their required printing functions based on this SDK.

1、Scope of application

This SDK is suitable for the majority of program developers who have the following capabilities or conditions:
① Write applications based on the C language dynamic library functional interface under Windows or Linux systems.
② Persons who have a certain understanding of the functions and usage specifications of barcode label printers.
③ Personnel who have a certain understanding of RFID reading and writing functions.

2、System Platform

① Windows PC platform (32/64 bit): XP, win7, win8, win8.1, win10, etc.
② VC runtime environment support, etc.
③ Linux platform, supports x86_64 and aarch64 platforms.

3、programming language

Programming languages ​​that support .dll-based programming languages ​​include but are not limited to: C/C++, C#, Basic (VB, VB .NET), Pascal (Delphi), Java, PowerScript (PB).
Support .so-based programming languages ​​include but are not limited to: C/C++, Java.
Supports web API calls based on http include but are not limited to: javascript, C#, C++.
