seqNo string necessary A uniquely numbered packet sequence assigned by the Requesting party. The Answering party must use the same value to reply to the Requesting party.；

inParams.recvTimeout string necessary The timeout period for communication reception (unit: ms). (Note: Please fill in a positive integer string.)
"recvTimeout":"20000"；

    "inParams":{
