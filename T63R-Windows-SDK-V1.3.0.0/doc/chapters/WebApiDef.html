web_DSTP2x_GetLibVersion(获取本库版本号)

请求
参数 类型 存在必要性 含义
version string 必要 web 通讯协议版本；
"version"= "1.0"；默认
seqNo string 必要 由请求方分配的具有唯一性的包序号，应答方需使用相同值回复请求方；
"seqNo"= "0001"；
funcName string 必要 执行标识；
"funcName"= "web_DSTP2x_GetLibVersion"；
参考例子：
{
    "version":"1.0",
    "seqNo":"0001",
    "funcName":"web_DSTP2x_GetLibVersion"
}
应答
参数 类型 存在必要性 含义
version string 必要 web 通讯协议版本；
"version"= "1.0"；默认
seqNo string 必要 由请求方分配的具有唯一性的包序号，应答方需使用相同值回复请求方；
"seqNo"= "0001"；
funcName string 必要 执行标识；
"funcName"= "web_DSTP2x_GetLibVersion"；
rtnCode string 必要 执行结果码。返回"0"执行成功，非"0"表示执行失败；
"rtnCode":"0"；
rsltMsg string 必要 执行结果描述。
"rsltMsg":"OK"；
outParams {} 非必要 应答数据结构；
outParams.libVersion string 必要 动态库版本信息；
"libVersion":"1.1.0.0"；
参考例子：
{
    "version":"1.0",
    "seqNo":"10",
    "funcName":"web_DSTP2x_GetLibVersion"
    "rtnCode":"0"
    "rsltMsg":"OK"
    "outParams":{
        "libVersion":"1.1.0.0"
    }
}
