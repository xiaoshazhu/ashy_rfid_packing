Chapter 2, Function List


function specification
Printer connection 1. Supports enumeration and connection of USB/network port/serial port printers.
2. Supports setting the timeout time for data sending and receiving of USB/TCP (network port)/serial port.
Note: When the printer is connected to the PC via USB, please ensure that the printer is exclusively occupied by a certain application program. It is not allowed to run two application programs based on the DSTP2x-SDK simultaneously, or to run an application program based on the DSTP2x-SDK and the printer driver program at the same time.
Printer control and management 1. Initialize the printer.
2. Restart the printer.
3. Position the label.
4. Set the cutter and DPI.
5. Configure network port settings.
6. Print the self - test page.
Printer information query 1. Obtain manufacturing information such as printer name, manufacturer name, printer serial number, and main program version number.
2. Check whether the printer has abnormal states such as paper out, ribbon out, or print head up.
3. Query printer status information, such as paper type, emulation mode, whether the cutter is enabled, printer warning status, printer error status, etc.
4. Query the printer's extended main status, warnings, and abnormal states.
Print 1. Canvas drawing and printing:
Text, barcodes, QR codes, picture tables, and their corresponding decoration settings, such as font type, font size, bold, italic, etc.
① Text support: Simplified/Traditional Chinese characters, English, etc.
② Barcode/QR code support: Code39, Code93, Code128, PDF417, QRCode, etc.
③ Picture format support: jpg, png, bmp, etc.
④ Table printing: Generate tables with customized rows and columns.
2. Offset and area settings:
(1) Set the starting horizontal offset of the label.
(2) Set the label printing range.
3. Image processing property settings
(1) Error diffusion setting
(2) Ordered dithering setting
(3) Threshold setting
4. Printing through templates
5. Obtain the preview image generated by overlay printing
RFID(Optional items) 1. Read and write EPC, read and write data in the form of strings and hexadecimal.
2. Read and write USER, read and write in the form of strings and hexadecimal (optional item. Specifically, check whether the label specification supports this area).
3. Set and obtain the read and write power of the printer.
4. Read TID.
5. RFID label positioning.
