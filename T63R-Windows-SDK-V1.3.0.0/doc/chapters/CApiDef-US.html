  [in,out]    pMainStatusNum   When passed in as an input parameter, it represents the size of the pMainStatus array. When passed out as an output parameter, it represents the number of main statuses actually stored in pMainStatus. If 0 is passed in, it means that the parameter is not used.
  [out]       pWarning         An array used to store warnings when the function returns. It is recommended to pre-allocate 8 array elements. If 0 is passed in, it means that the parameter is not used.
  [in,out]    pWarningNum      When passed in as an input parameter, it represents the size of the pWarning array. When passed out as an output parameter, it represents the number of warning messages actually stored in pWarnings. If 0 is passed in, it means that the parameter is not used.

  [in,out]    pErrorNum        When passed in as an input parameter, it represents the size of the pError array. When passed out as an output parameter, it represents the number of error messages actually stored in pError. If 0 is passed in, it means that the parameter is not used.
  [out]       pDesc            Detailed descriptions of status, warnings, and errors, etc. The returned string format is like: \nMain status: xxx, xxx|Warning: None|Error: xxx, xxx|Paper type|Print mode|Cutter status|Peeler status|Sensor status; \nIf 0 is passed in, it means that the parameter is not used.
  [in,out]    pDescLen         When passed in as an input parameter, it represents the length of the pDesc buffer. When passed out as an output parameter, it represents the length of the actual returned pDesc content. If 0 is passed in, it means that the parameter is not used.

DSTP2x_PrintPdf (Print PDF)

unsigned int DSSDK DSTP2x_PrintPdf(DEV_HDL ullDevHdl, PDF_HDL ullPdfHdl, int nPageNo, char *szOutFile, int *pOutFileSize, int nRfidReadType, char *szOutRFID, int *pOutRFIDSize);

illustrate：
 The local files in the format of.png or.prn will be generated for the szOutFile parameter only when the DSTP2x_SetPdfPrnMode function is called and the value of nPrnMode is either 1 or 2.
 In order to enable the RFID function, the DSTP2x_SetPdfPrnMode function needs to be set to 0.
 For the requirement that the RFID has both writing and reading functions simultaneously, the DSTP2x_SetPdfRFIDData function needs to be called first, and the reading type in nRfidReadType should be set and the memory of szOutRFID should be allocated.
 For the requirement of the RFID's read-only function, there is no need to call the DSTP2x_SetPdfRFIDData interface, but the memory of szOutRFID needs to be allocated.
 If the RFID reading function is not required, both nRfidReadType and szOutRFID need to be set to 0. 

parameter:
  [in]        ullDevHdl           DEVICE ADDRESS
  [in]        ullPdfHdl           The PDF file handle returned by the DSTP2x_LoadPdf function.
  [in]        nPageNo             The page number of the PDF file to be printed.
  [out]       szOutFile           Used to store the file name (including the path) of the local data (either.prn or.png) generated by this printing operation. 
                                  It is recommended to pre - allocate a space of no less than 1024 bytes. 
                                  If there is no need to obtain the file name of the local data generated by this printing operation, just pass 0 for this parameter.
  [in,out]    pOutFileSize        As an input parameter, it represents the buffer size of szOutFile. As an output parameter, it represents the length of the string actually stored in szOutFile. If szOutFile is 0, this parameter will be ignored.
  [in]        nRfidReadType       nRfidReadType Indicates whether to read and how to read RFID data during the process of printing the current page data.
                                  0 - Do not read
                                  1 - Read TID
                                  2 - Read EPC
                                  4 - Read USER
  [out]        szOutRFID          A buffer used to store the RFID data read during the printing process. Please determine the pre - allocated buffer space size according to the (combined) type of nRfidReadType. 
                                  The read RFID data is returned after the dynamic execution of RFID operations and is represented as a hexadecimal string. 
                                  The content format is, for example: "TID:82309360|EPC:0123456789| USER:abcdef". 
                                  If there is no need to obtain the RFID data read during the printing process, just pass 0 for this parameter.
  [in,out]    pOutRFIDSize        入参时表示szOutRFID的缓冲区大小，出参时表示实际存入szOutRFID的数据长度；如szOutRFID为0，本parameter将被忽略
