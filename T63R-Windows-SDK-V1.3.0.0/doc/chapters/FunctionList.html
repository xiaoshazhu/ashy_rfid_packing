第二章、功能清单


功能 规格说明
打印机连接 1.支持枚举、连接 USB/网口/串口打印机
2.支持设置 USB/TCP（网口）/串口数据收发超时时间
注：当打印机以 USB 连接 PC 机时，请确保该打印机仅为某一应用程序独占。不可同时运行两个基于 DSTP2x-SDK 的应用程序，或者不可同时运行基于 DSTP2x-SDK 的应用程序与打印机驱动程序。
打印机控制、管理 1.初始化打印机
2.重启打印机
3.标签定位
4.切刀，DPI 设置
5.网口相关设置
7.打印自检页
打印机信息查询 1.获取打印机名、厂商名、打印机序列号、主程序版本号等生产制造信息
2.获取打印机是否缺纸、缺碳带、印头抬起等异常状态
3.查询打印机状态信息，如机纸张类型、仿真模式、切刀是否开启、打印机警告状态、打印机错误状态等信息
4.查询打印机扩展主状态、警告、异常状态
打印 1.画布绘制打印：
文本、条形码、二维码、图片表格，及其相应的修饰设置，如字体类型、字体大小、加粗、斜体等
①文本支持：简体/繁体汉字、英文等
②条码/二维码支持：Code39、Code93、Code128、PDF417、QRCode 等
③图片格式支持：jpg、png、bmp 等
④表格打印：自定义行列生成表格
2.偏移及区域设置：
(1)设置标签起始横向偏移量
(2)设置标签打印范围
3.图像处理属性设置
(1)误差扩散设置
(2)有序抖动设置
(3)阈值设置
4.通过模板打印
5.获取套打生成的预览图
RFID(选件) 1.读写 EPC，字符串和 16 进制读写数据
2.读写 USER，字符串和 16 进制读写读写(选件，具体查看标签规格书是否支持该区域)
3.设置、获取打印机的读写功率
4.读取 TID
5.RFID标签定位
