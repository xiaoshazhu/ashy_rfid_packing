Definition of printer status codes
  • Definition of printer status codes
    • Main status code (code segment: 1 - 999)
    • Warning code (code segment: 1000 - 1999)
    • Error code (code segment: 2000 - 2999)

Main status code (code segment: 1 - 999)

Decimal Code Value Meaning of Status Code
1 Device is idle
2 Device is busy
3 There is printing data in the printer
4 There is no printing data in the printer
5 USB anti-pulse mode communication failed
6 Label reading and writing completed
7 Retry cancellation process is in progress
8 Reprint process is in progress
9 RFID automatic verification is in progress
10 RFID custom instruction is in progress
11 There is no RFID module

Warning code (code segment: 1000 - 1999)

Decimal Code Value Meaning of Warning Code
1000 The paper is nearly running out

Error code (code segment: 2000 - 2999)

Decimal Code Value Meaning of Error Code
2000 Label or black mark positioning error
2001 Paper jam
2002 Paper tearing error
2003 Out of paper
2004 Cutter error
2005 Paper loading error
2006 Ribbon error
2007 Print head lifted
2008 Print head overheated
2009 EPC data missing in print data
2010 RFID re - printing failed
2011 RFID calibration failed
2012 RFID error reported
2013 Paused or offline
2014 The stripper has an error
